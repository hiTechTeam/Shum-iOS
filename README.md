# Shum — iOS

Независимый форк Telescan с собственным приложением `hiTeam.ShumiOS`, контейнером, ключами и Bluetooth UUID. Исходные Telescan и Spotchat не изменяются. Приватный репозиторий: https://github.com/hiTechTeam/Shum-iOS.

Открыть `ShumiOS.xcodeproj`, схема `Shum`. iOS 16+, Xcode 26. Команда подписи — из настроек проекта.

## Возможности

- Пиксельное облачко без глаз, зелёный акцент и прямоугольные основные кнопки. Вкладки **Люди — Чаты — Профиль** с пиксельными иконками.
- Регистрация по имени, необязательное фото. Username и номер телефона не нужны. Редактирование имени, фото и описания через карточки Telescan.
- Текущие чаты Spotchat: поиск, группировка пузырей, даты, копирование текста, клавиатура, просмотр профиля и фото, повтор отправки, статусы доставки и прочтения.
- Постоянные подписанные контакты, QR-код, сканирование камерой или из фото, ссылки `shum://contact`, системное приглашение и входящие запросы на добавление.
- Прямая доставка через Bluetooth, пересылка зашифрованных пакетов через соседние устройства и интернет-доставка через Nostr relays.
- Зашифрованные постоянные история и очередь. Повтор отправки, дедупликация, подписанные подтверждения, блокировка контакта, локальное удаление чата и профиля.
- Перенос зашифрованной истории первой версии Shum без смены Noise-ключей. Старые сообщения присоединяются к проверенному контакту по отпечатку ключа, а не по имени. До повторного обмена контактами доступна история без отправки.

## Шифрование и границы

Перенесён именно текущий протокол Spotchat/BitChat: Noise и подписанные зашифрованные courier-пакеты, помещённые в частный Nostr-конверт с одноразовым внешним ключом. Этот конверт **не совместим с NIP-17/NIP-44/NIP-59**: совпадающие номера kind не означают соответствия этим стандартам. Криптографическая реализация находится в `Vendor/Bluetooth` и `Vendor/Nostr`; secp256k1 — пакет P256K 0.21.1.

История второй версии защищена ChaCha20-Poly1305, первой — AES-GCM. Ключи — в Keychain этого приложения. Relay не получает поле с открытым текстом переписки. Используются прямые TLS-соединения с Nostr relays, Tor не включён.

Текущий чат поддерживает текст до 4096 байт UTF-8, очередь до 200 исходящих сообщений и срок ожидания доставки до 24 часов. Звонки, вложения и группы в этот пользовательский интерфейс ещё не подключены. Постоянной фоновой push-доставки нет: iOS может приостановить соединения, получение возобновляется при открытии Shum. Эта сборка для проверки на устройствах, не публикация в App Store.

## Проверка

12 сентября 2026: 140 тестов в 12 наборах прошли. Отдельный реальный Nostr-тест доставки и подписанного подтверждения прочтения без Bluetooth прошёл за 44,6 секунды. В подписанной сборке симулятора вручную проверены регистрация по одному имени, переход в чаты и сохранение изменённого имени. Сборка 4 установлена и запущена на iPhone 11 и iPhone 14 Pro.

`ShumTests` содержит проверки регистрации без username, совместимости старых карточек, переноса истории, управления видимостью, профилей, очереди, Noise и Nostr, подмены ключей/подписей/подтверждений, ошибок диска, блокировки, удаления и повторного получения сообщений.

```sh
xcodebuild -project ShumiOS.xcodeproj -scheme Shum \
  -destination 'platform=iOS Simulator,name=iPhone 17' \
  -parallel-testing-enabled NO CODE_SIGNING_ALLOWED=NO test
```

Сетевые тесты включаются отдельно: `ShumLiveMessengerTests` требует переменную окружения тестового процесса `SHUM_LIVE_NOSTR=1`. Он создаёт только временные тестовые ключи, проверяет шифрованное сообщение и подписанное подтверждение прочтения через реальные relays при отключённом Bluetooth. Обычный запуск тестов этот обмен пропускает.

Debug Simulator: `-ShumPreview` — демонстрационные чаты без радио; вместе с `-ShumPreviewChat` — сразу экран переписки. Обычный запуск не создаёт демонстрационных контактов.

## Происхождение

`Vendor/Messaging`, `Vendor/Nostr` и защищённый транспорт изначально перенесены из рабочей копии соседнего Spotchat-iOS (базовый коммит `803781b`). Транспорт синхронизируется с официальным Bitchat через закреплённый upstream; его исходная лицензия — Unlicense. Telegram-iOS используется только как GPL-референс интерфейсного поведения без компиляции или копирования его исходников. Точные версии и порядок обновления описаны в `Upstreams/README.md`; исходная лицензия Telescan — `LICENSE.md`.
