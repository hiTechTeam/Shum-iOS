# Shum iOS

[English](README.md) · Русский

Shum для iPhone. Общайтесь с людьми рядом по Bluetooth и на расстоянии через независимые релеи Nostr. Номер телефона не нужен.

## Возможности

- Текстовые сообщения по Bluetooth без интернета или через интернет-релеи.
- Сквозное шифрование и зашифрованная история на устройстве.
- Резервные копии профиля и переписки.
- Код приложения, биометрия и скрытие переписки в переключателе приложений.
- Пиксельные аватары, созданные на устройстве из seed.
- QR-карточки, которые добавляются и при офлайн-собеседнике.

Сохранение контакта и принятие приглашения в чат происходят отдельно. Сообщения идут по Bluetooth или через независимые релеи. Сервер разработчиков отправляет push-уведомления, не получая текст сообщений.

Приложение реализует текущий черновик v1. Синхронизация устройств и переход на общее ядро Rust запланированы.
